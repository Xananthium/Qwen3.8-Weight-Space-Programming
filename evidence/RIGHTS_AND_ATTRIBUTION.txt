HLE DATASET
Official cais/hle is MIT-tagged, auto-gated, and explicitly asks users not to publicly share, re-upload or distribute the dataset to preserve benchmark integrity. Its public card includes no-training contamination guidance. These are distinct observations: gating is an access mechanism, MIT is a license declaration, and the integrity request should not be misrepresented as an independently established categorical legal prohibition. Any conditions accepted by the original account are not reproduced or assumed transferable here. Public raw README retrieval returned401; the public dataset page and metadata exposed the declaration/request. The experiment pinned5a81a4c7271a2a2a312b9a690f0c2fde837e4c29, matching the verified source parquet.

Publication policy: respect the explicit integrity request by omitting benchmark questions, images, reference rationales, official answer labels and losslessly decodable prompt token arrays from this public evidence export. Raw API jobs/results contain all of these and are not safe to copy wholesale. A model-generated output is not automatically independent of the benchmark: it can quote or reconstruct the question, options or solution. Raw generated HLE text/token arrays are therefore hash-inventoried but not rehosted in this package. New selective excerpts require separate content review; a blanket label of 'our outputs' does not perform that review.

Public scientific observations include case IDs, aggregate/per-case correctness and cutoff statuses, token counts, timings, candidate hashes, source hashes and methods. No raw answer or low-entropy standalone answer hash is published. IDs permit authorized dataset users to locate the exact cases. Scripts reconstruct source records only after each reproducer independently obtains authorized source access; they do not bypass gating. A private raw-output archive remains needed for exact historical proof review. Source hashes verify bytes if supplied through an appropriate channel; rerunning a model cannot be promised to reproduce sampled outputs exactly.
