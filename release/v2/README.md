# Calmer V2 merged GGUF export evidence

The local release artifact is `Calmer-V2-Qwen3.8-27B-Q4_K_P-F32Edits.gguf` (19,104,353,280 bytes; SHA-256 `8c046db3518f3711f797a832153362f413aa29e9ab8aef675f88a0842291c1a1`). It is built from the original packed HauhauCS GGUF (SHA-256 `ba36dc3c2b2ff5e0aa5d71092a8894546996a6a119ae391803dda07cdc08516d`) and the exact tested V2 pilot NPZ (SHA-256 `c12820b9bc65e691853a1073c8647fed47cb5521ef3fbcd19817d684006debba`) at global alpha 1.5.

The [exporter](../../tools/export_calmer_v2_gguf.py) materializes `W_new = dequant(W) - 1.5 outer(u, coeff)` in FP32 for MLP down projections at zero-based layers **18, 49, 50, 51**. These four Q5_K tensors become F32. All other **862 of 866 tensor payloads** retain their original type and exact encoded bytes. [The full manifest](merged_export_manifest.json) records every tensor hash, changed columns, and FP32 random-probe algebra checks; [metadata_audit.json](metadata_audit.json) verifies source metadata preservation, including `general.license.name` and `general.license.link`, apart from the intentional model-name change and added edit provenance fields. [Delta preservation audit](delta_preservation_audit.json) confirms that the six layer-49/50/51 vectors are byte-identical to V1; V2 adds the layer-18 pair.

The [native CPU smoke](native_smoke.json) loaded this GGUF with llama.cpp, zero GPU layers, and two CPU threads, then answered a simple `2 + 2` prompt with **4**. The captured [stdout](native_smoke_stdout.txt), [stderr](native_smoke_stderr.txt), and [prompt](native_smoke_prompt.txt) are provided for inspection. This validates loading and decoding, not HLE/GSM quality or numerical equivalence to the tested compiled profile.

The tested V2 pilot used the packed GGUF plus a fixed FP32 sidecar update, cast to BF16 before tensor-parallel all-reduce. The merged GGUF uses F32 materialized matrices in a native GGUF engine. Benchmark results from the pilot therefore belong to the sidecar representation; the merged export has its own provenance and only a load/decode smoke so far.
